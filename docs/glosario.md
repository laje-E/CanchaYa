# glosario.md

- **Cancha:** espacio físico habilitado para practicar un deporte.
- **Turno:** intervalo de tiempo solicitado para utilizar una cancha.
- **Reserva:** asignación confirmada de una cancha a un usuario durante un turno.
- **Franja pico:** horario desde las 18:00, al que se aplica un recargo del 20%.
- **Solapamiento:** intersección temporal entre dos reservas de la misma cancha.
- **Reserva activa:** reserva en estado PENDING o CONFIRMED cuyo inicio todavía no pasó.
- **Cancelación:** cambio del estado de una reserva CONFIRMED a CANCELLED.
- **Administrador:** usuario con permisos para crear y administrar canchas.
- **Disponibilidad:** posibilidad de reservar un intervalo sin conflictos y dentro del horario de atención.
