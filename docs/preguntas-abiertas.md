# preguntas-abiertas.md

Las siguientes decisiones deben validarse antes de una operación comercial real. Para el MVP académico se aplican los supuestos de `decisiones.md`.

| Prioridad | Pregunta | Regla afectada | Impacto |
|---|---|---|---|
| Alta | ¿Cada establecimiento tendrá su propia cuenta administradora? | RN12 | Define permisos y aislamiento de datos. |
| Alta | ¿Se exigirá seña o pago completo? | RN13 | Afecta confirmación, vencimientos y reembolsos. |
| Media | ¿Cómo se tratan feriados y cierres excepcionales? | RN4 | Puede bloquear horarios específicos. |
| Media | ¿Se permiten reservas recurrentes? | RN14 | Requiere generar y validar múltiples turnos. |
| Media | ¿Qué política se aplica ante lluvia o fuerza mayor? | RN15 | Define cancelación y devolución. |
